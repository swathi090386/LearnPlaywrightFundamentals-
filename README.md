# Learn Playwright Fundamentals

This repository contains a Playwright test project for learning browser automation with TypeScript.

## Contents

- `tests/` - Playwright test files, including basic examples and annotations.
- `playwright.config.ts` - Playwright configuration.
- `package.json` - Project dependencies and scripts.
- `.gitignore` - Files and directories excluded from version control.

## Setup

```bash
npm install
```

## Run tests

```bash
npx playwright test
```

## Notes

- This project uses Playwright with TypeScript.
- Temporary artifacts like `node_modules`, `playwright-report`, and `test-results` are ignored.
